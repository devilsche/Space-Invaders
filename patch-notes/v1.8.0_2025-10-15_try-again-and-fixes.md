# Patch Notes v1.8.0 - Try Again Feature & Critical Fixes
**Release Date:** October 15, 2025

## 🎮 New Features

### Try Again System
- **Normal Mode**: Added "Try Again" option on Top 10 leaderboard screen
  - `[ENTER]` to restart Normal Mode immediately
  - `[ESC]` to return to main menu
- **Victory Screen**: Improved controls clarity
  - `[SPACE]` Try Again - immediately restart current game mode
  - `[ESC]` Continue - proceed to name input (Normal Mode) or menu (Survivor Mode)
- **Survivor Mode**: Already had Try Again functionality, now consistent with Normal Mode

### Complete Try Again Flow
- **Normal Mode**: Victory → Name Input → Top 10 → **Try Again** or Menu
- **Survivor Mode**: Name Input → Game Over Screen → **Try Again** (Ship Select) or Menu

## 🐛 Critical Bug Fixes

### Kill Counting System Overhaul
**Issue**: AoE weapons (HomingRocket, Rocket, Blaster, Nuke) were not counting kills in Survivor Mode
- Kills from AoE damage were only updating `_total_kills` but NOT mode-specific counters
- Kill counter notification was never displayed for AoE kills
- Affected both Normal Mode and Survivor Mode

**Fix**: Enhanced `_apply_aoe()` function in `entities/projectile.py`
- Added mode-specific kill tracking for all AoE kills:
  - Survivor Mode: Increments `survivor_kills`
  - Normal Mode: Increments `kills`
- Added `_show_kill_counter()` call for each AoE kill
- Applied to all enemy types: regular enemies, fly-in enemies, and boss
- Now HomingRocket kills properly count and display kill notifications! 🎯

### Highscore Data Integrity
**Issue**: Legacy `save_highscore()` function was destroying new format data
- Old function wrote `{"highscore": 12345}` format on game exit
- Completely overwrote all Top 10 data with names, kills, and levels
- Data had to be restored from Firebase after each game session

**Fix**: Completely rewrote `save_highscore()` in `system/utils.py`
- Now reads and preserves new list format: `[{score, name, kills, level}, ...]`
- Only updates if new highscore is higher than best existing score
- Maintains Top 10 list with proper sorting
- Backward compatible with old format (auto-converts)
- New format data is now safe! 🛡️
