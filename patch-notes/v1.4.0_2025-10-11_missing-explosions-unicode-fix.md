## 🐛 Behobene Bugs

### 1. **ExplosionManager Object Pool Bug**
**Problem:** Explosionen aus dem Object Pool wurden recycled, aber nicht wieder zur aktiven Liste hinzugefügt → Explosionen wurden nicht angezeigt (invisible explosions)

**Lösung:** `manager/explosion_manager.py` Line 146
```python
# FIXED: Explosion nach Recycling wieder zur aktiven Liste hinzufügen
self.explosions.append(explosion)
```

**Impact:** ✅ Alle Explosionen werden jetzt korrekt angezeigt, auch nach mehreren Spielrunden

---

### 2. **Fehlende DESTROY-Explosionen bei AoE-Waffen**
**Problem:** Enemies, die durch AoE-Damage starben (nicht durch direkten Treffer), erhielten keine DESTROY-Explosion

**Symptom:** HomingRocket zeigte 11 Kills aber nur 7 DESTROY-Explosionen (4 fehlten)

**Root Cause:**
- `will_die=True`: Enemy stirbt durch direkten Treffer → DESTROY-Explosion wird erstellt ✅
- `will_die=False`: Enemy überlebt direkten Treffer, stirbt aber durch `take_damage()` → KEINE Explosion ❌

**Lösung:** `game/game.py` Lines 855-882
```python
if dead:
    # DESTROY-Explosion erstellen wenn noch keine existiert
    # (z.B. wenn Enemy erst durch AoE-Schaden stirbt)
    if not will_die and weapon_owner == "player":
        print(f"[{timestamp}ms]   DESTROY-Explosion (killed by AoE damage): Creating at ({enemy_x},{enemy_y})")
        # ... Explosion erstellen
```

**Impact:** ✅ Jetzt werden alle Kills mit DESTROY-Explosionen visualisiert (100% Ratio)

---

### 3. **Unicode Encoding Crash (Windows)**
**Problem:** `UnicodeEncodeError: 'charmap' codec can't encode character` bei Emojis in Print-Statements

**Root Cause:** Windows Console verwendet cp1252 Encoding (kein Unicode-Support), Python 3.13 versucht Emojis zu drucken → Crash

**Betroffene Emojis:**
- 🎯💥💀 (Explosion/Kill Tracking)
- 🛡️⚡🚀 (PowerUp Aktivierung)
- ⚠️ (Warnungen)
- 🔍 (Debug Output)
- 🗑️📊✅❌☠️💚♻️🆕🔧🖼️ (verschiedene Debug-Marker)

**Lösung:** Alle Emojis durch Plain-Text ersetzt:
- `game/game.py`: 20+ Print-Statements
- `manager/explosion_manager.py`: 5 Print-Statements
- `manager/projectile_manager.py`: 2 Logging-Statements

**Beispiel:**
```python
# BEFORE (crashed):
print(f"⚠️ WARNING: Asset FPS={fps} too slow")

# AFTER (fixed):
print(f"[WARNING] Asset FPS={fps} too slow")
```

**Impact:** ✅ Spiel läuft ohne Crashes auf Windows-Systemen mit cp1252 Console

**Impact:** ✅ Statistiken zeigen korrekte Werte: `Total = HIT + DESTROY`
