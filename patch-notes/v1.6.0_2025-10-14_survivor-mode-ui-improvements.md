# Patch Notes v1.6.0 - Survivor Mode UI Improvements
**Release Date:** October 14, 2025

## 🎮 Major Features

### Survivor Mode Enhancements
- **Live Highscore Display**: Survivor mode now shows the current best time and kills in the top-left corner
  - Display updates in real-time when player beats the current record
  - Shows "Best Time" and "Best Kills" instead of regular score in survivor mode
  - Color-coded: Time in red (255, 100, 100), Kills in yellow (255, 255, 100)

### Victory Screen Polish
- **Explosion Completion**: Victory screen now waits for all explosions to finish before appearing
  - Improved visual flow and game feel
  - No more abrupt transitions after boss kill

## 🎨 UI/UX Improvements

### Survivor Mode Display
- **Top-Left HUD**: Replaced score display with survivor-specific stats
  - Normal mode: Shows "Score" and "High Score" as before
  - Survivor mode: Shows "Best Time" and "Best Kills"
  - Real-time updates when beating current record

### Menu & Leaderboard Adjustments
- **Leaderboard Positioning**: "TOP 10 TIMES" title moved 20px lower for better spacing
  - Changed from `-int(100 * ui_scale)` to `-int(80 * ui_scale)`

## 🔧 Technical Changes

### Code Structure
- **Import Optimization**: Added `load_survivor_highscores` to main imports
  - Prevents NameError during survivor mode gameplay
  - Improves code organization and performance

### Game State Logic
- **Victory Condition**: Enhanced victory detection to include explosion completion
  - Added check: `len(self.explosion_manager.explosions) == 0`
  - Ensures smooth visual experience before showing victory screen

## 🐛 Bug Fixes
- Fixed NameError when entering survivor mode (missing import)
- Fixed abrupt victory screen appearing before explosions finish

## 📝 Files Modified
- `game/game.py`: 
  - Added `load_survivor_highscores` import
  - Implemented dynamic highscore display in `_draw()`
  - Enhanced victory condition check
  - Position adjustments for name input screen
- `system/menu.py`: Menu spacing and position adjustments
- `system/utils.py`: Survivor highscore management functions
- `data/survivor_highscores.json`: Highscore data storage

None
