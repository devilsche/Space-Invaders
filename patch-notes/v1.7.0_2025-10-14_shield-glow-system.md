# Patch Notes v1.7.0 - Shield Glow Animation System
**Release Date:** October 14, 2025

## 🛡️ Major Features

### New Shield Glow Visual System
- Added animated shield glow sprite system using `ShieldGlow.png` (1024x1024, 4x4 grid, 16 frames)
- Implemented smooth shield animation with configurable frame rate
- Optional rotation feature (11.25° per frame, full 360° rotation over 2 cycles)
- Adjustable transparency (Alpha channel support, 50-255 range)
- Stage-specific shield scaling for all 4 ship types

### Test Script (`test_shield_glow.py`)
Interactive testing tool for shield visualization:
- **Ship Selection**: Press 1-4 to switch between Stage 1-4 ships
- **Shield Scaling**: UP/DOWN arrows to adjust size
- **Rotation Toggle**: R key to enable/disable rotation
- **Transparency Control**: A/S keys to adjust alpha (20-100%)
- **Animation Speed**: LEFT/RIGHT arrows to adjust frame rate
- **Pause/Resume**: SPACE key

## 🎮 Gameplay Changes

### Survivor Mode Enhancements
- **Stage-Specific Highscores**: Separate Top 10 leaderboards for each stage (Rookie/Veteran/Elite/Legend)
- **Record Display**: Current stage record shown in top-left during gameplay
  - Shows stage name, best time, and record holder's name
  - Updates automatically when stage is selected
- **Improved Highscore System**: Maintains up to 40 entries (10 per stage)

### Music System Improvements
- Menu music now plays in all non-gameplay screens:
  - Ship Selection screen
  - Victory screen
  - Survivor Name Input screen
  - Survivor Game Over screen
- Game music only plays during active gameplay
- Smooth transitions between menu and game music

## 🎨 UI/UX Improvements

### Font System Overhaul
- **New Controls Font**: All control hints now use `KGRedHands.ttf` for consistent handwritten style
- **Unified Font Sizes**: Controls text standardized to 32 * ui_scale across all screens
- **Consistent Positioning**: All controls placed at `ch - int(80 * ui_scale)` from bottom
- **Font Configuration**: Added controls font to `config/fonts.py` with 3 size options

### Screen Consistency
- Victory Screen controls now match other screens in size
- Ship Selection controls updated
- Survivor screens (Name Input & Game Over) updated
- All screens maintain visual consistency

## 🐛 Bug Fixes

### Critical Fixes
- Fixed menu music continuing during gameplay in Survivor mode
- Fixed Victory screen crash due to incorrect parameter order

- Fixed controls font inconsistency across different screens

### Minor Fixes

## 📊 Data Structure Changes

### Survivor Highscores (`data/survivor_highscores.json`)
**Old Format:**
```json
[
  {"time": 229.458, "kills": 261, "name": "Player"}
]
```

**New Format:**
```json
[
  {"time": 229.458, "kills": 261, "name": "Player", "stage": 1}
]
```
- Added `stage` field (1-4) to all entries
- Reset existing highscores to accommodate new structure

### Configuration Files
**`config/fonts.py`** - Added controls font configuration:
```python
"controls": {
    "file": "assets/fonts/KGRedHands.ttf",
    "sizes": {"large": 48, "normal": 36, "small": 28}
}
```

## 🎯 Configuration Recommendations

### Shield Glow Settings (from testing)
Recommended configurations per stage:
- **Stage 1** (80x80): scale 0.5, alpha 100-150
- **Stage 2** (90x90): scale 0.6, alpha 100-150
- **Stage 3** (100x100): scale 0.7, alpha 100-150
- **Stage 4** (130x130): scale 1.0, alpha 100-150

Rotation: Optional, recommended OFF for gameplay (can be distracting)
Animation Speed: 0.3 frames/update provides smooth visual effect
